# SendEGram MVP Scope

**Document ID:** SEG-MVP-001

**Version:** 1.0

**Status:** Draft

---

# Purpose

This document defines the exact scope of the first public version of SendEGram.

Anything not listed here is considered out of scope for Version 1.0.

---

# MVP Goal

Enable Uzbek citizens living abroad to:

1. Send money to Uzbekistan through licensed partners.
2. Pay essential bills for themselves or their families.
3. Track payments and transfers.
4. Receive intelligent financial reminders powered by AI.

If users consistently return to SendEGram for these tasks, the MVP is successful.

---

# Target Market

Primary:

Uzbek citizens living abroad.

Secondary:

Families living in Uzbekistan.

---

# Core User Journey

Open the app.

↓

Login securely.

↓

Select recipient.

↓

Send money.

↓

Receive confirmation.

↓

AI identifies unpaid bills (if available).

↓

User reviews suggested payments.

↓

User confirms.

↓

Payments completed.

↓

Transaction history updated.

# Included Features

## Authentication

* Phone number registration
* OTP verification
* Secure login
* Device management

---

## User Profile

* Personal information
* Language selection
* Security settings
* Notification preferences

---

## Identity Verification (KYC)

* Identity document upload
* Selfie verification (subject to provider capabilities)
* Verification status

---

## International Money Transfer

* Country selection
* Amount calculation
* Exchange rate display
* Fee estimation
* Transfer tracking
* Transfer history

---

## Bill Payments

* Electricity
* Natural Gas
* Water
* Internet
* Mobile Top-Up
* Television

---

## AI Features

* Spending insights
* Bill reminders
* Payment suggestions

Important:

AI never performs financial actions without explicit user confirmation.

---

## Notifications

* Transfer completed
* Payment completed
* Failed transactions
* Security alerts
* AI reminders

---

## Transaction History

* Search
* Filters
* Export receipt

---

# Not Included

The following features are intentionally excluded from Version 1.0:

* Digital wallet
* QR payments
* Merchant platform
* Business accounts
* Savings
* Loans
* Insurance
* Investments
* Cryptocurrency
* Physical cards
* Virtual cards
* Developer API

---

# Success Criteria

The MVP is considered successful when:

* Users complete transfers without assistance.
* Users return to the app regularly.
* Bill payments increase user retention.
* AI recommendations are actively used.
* Customer satisfaction remains high.

---

# Exit Criteria

Version 1.0 is complete only when:

* All critical user journeys work reliably.
* Security review is passed.
* Partner integrations are stable.
* Performance targets are met.
* Internal testing is completed.
* Public beta feedback is addressed.
