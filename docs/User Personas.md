# Purpose

This document defines the primary user groups for SendEGram.

Every product decision must solve a real problem for at least one of these personas.

---

# Persona 1 — Russian Migrant Worker

## Priority

★★★★★

## Profile

* Age: 24–45
* Lives in: Russia
* Works in construction, logistics, manufacturing or services
* Sends money to family every month

## Goals

* Send money safely
* Minimize transfer fees
* Save time
* Help family members from abroad

## Pain Points

* Uses multiple applications
* Doesn't always know exchange rates
* Family still has to pay bills separately
* Complicated transfer process

## Opportunities

* Fast transfers
* AI reminders
* Family payment management
* Transfer history

# Design Principles Based on Personas

All user interfaces should:

* Minimize the number of required steps.
* Use clear and simple language.
* Always display fees before confirmation.
* Reduce cognitive load.
* Support both first-time and experienced users.

---

# Product Decisions

Every new feature must answer the following questions:

1. Which persona does this solve?
2. What problem does it solve?
3. Is the solution significantly better than existing alternatives?
4. Can the experience be simplified further?

If these questions cannot be answered clearly, the feature should not be included.
